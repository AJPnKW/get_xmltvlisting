IPTV EPG Reference

Reviewed from the research in C:\Users\andrew\PROJECTS\iptv and assembled into stable files in C:\Users\andrew\PROJECTS\GitHub\get_xmltvlisting\IPTV. Main strategy: one broad XMLTV file per focus country for quick device setup, with smaller provider-specific CA/US alternatives kept available where they are a better fit.

Recommended Use
  • Use the country files first when you want one EPG URL per country: CA, UK, AU, US.
  • Use the narrower provider-specific files for CA or US if your playlist closely matches those channel lineups.
  • Keep file references stable by using the raw GitHub URLs listed below in your IPTV app.
Important
  • The all-country US feed is very large at about 206.8 MB.
  • Some IPTV apps or lower-power devices may index faster with Xfinity, Verizon, or Broadcast Los Angeles instead.
  • The UK file is sourced from epg.pw under the GB region but published here as UK for device clarity.

Current Review Outcome

  • Best overall structure: separate country XMLTV files is the right strategy for your devices.
  • Best ready-to-use set: EPG_CA_Canada.xml, EPG_UK_UnitedKingdom.xml, EPG_AU_Australia.xml, EPG_US_UnitedStates.xml.
  • Best CA/US precision option: use the provider-specific files where your playlist source closely matches Rogers, Telus, Xfinity, Verizon, or LA Broadcast.
  • Source basis: the research repo provided country-level XMLTV cache files from epg.pw, and the delivery repo already contained smaller provider-based North American XMLTV outputs.
  • Local server hosting: HP920 LAN delivery uses http://192.168.1.73:8011/iptv-epg/ from the active static Python web server.
